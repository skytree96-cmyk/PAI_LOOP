            검증 완료는 발주기관·수행부서·계약일·근거 참조가 모두 필요하며, 수행 완료 실적은 종료일도 입력해야 합니다.
            
        
            
        
            
      
            
                

    
      
            
        
            입찰 결과
            입찰 결과 입력
            공고를 확인합니다.
            
        
            
        
            
          
          
          
          
            확인한 항목부터 초안으로 저장할 수 있습니다. 출처를 입력하고 필수 결과 정보를 확인한 뒤 ‘검증 완료’로 변경하세요.
            
          
          
          
          
          
          
          
            
          
            우리 투찰금액 ÷ 확인한 기준금액 × 100으로 계산합니다. 예정가격 또는 기초금액과 출처를 입력하세요. 결과는 소수 넷째 자리까지 표시합니다.
            
          
          
          
          
          
          
          
          
          
          
          
          
          
          
          
            개찰결과에서 확인한 분류번호와 재입찰번호를 함께 입력하세요. 미확인은 두 칸을 비워 두며, 0은 확인한 경우에만 입력합니다. 수기 입력만으로 나라장터 참여 확인이 되지는 않습니다.
            
          
            검증 완료로 저장하려면 결과의 출처가 필요합니다. 수기 비율은 근거 참조에 기준가격도 함께 적어주세요.
            
        
            
        
            
        
            
        
            
      
            
                

    
      
            
        
            
          
            사전규격 안내
            사전규격은 입찰공고 전 단계입니다
            
          
        
            
        
            
          
            사전규격 검색과 저장, 문서 분석은 서로 다른 단계입니다.
            
          
              
            
            1. 입찰공고 전 단계발주기관이 규격을 미리 공개하고 의견을 받는 단계이며 최종 입찰공고와 다를 수 있습니다.
              2. 
            
            2. 검색·저장 문서 분석 0회저장 자료 검색은 외부 조회 0회, 나라장터 검색·선택 저장도 문서 분석 0회입니다.
              3. 
            
            3. 선택 저장나라장터 검색 결과가 자동 저장되지 않습니다. 필요한 사전규격만 저장 버튼으로 선택합니다.
              4. 
            
            4. 분석은 별도 실행저장본 상세의 분석 버튼을 눌렀을 때만 문서를 분석합니다. 시간당 총량 제한은 없고 중복 실행 잠금과 공고별 재시도 대기는 유지됩니다.
              5. 
            
            5. GO 판정 아님분석 결과는 요구조건을 미리 구조화한 참고자료이며 입찰 참여 GO/NO-GO를 결정하지 않습니다.
              6.

              계정 및 분석 권한 관리
              
            
              외부 조회·유료 분석 권한은 나라장터 외부 조회와 개별 공고의 첨부 AI 분석에 사용됩니다. 분석 전 비용 확인은 계속 표시됩니다.
              
            
              권한을 바꾼 계정은 다시 로그인해야 합니다. 현재 관리자 계정도 동일하게 적용됩니다.
              
            
              비밀번호는 계정별로 입력해 재설정합니다. 현재 관리자 계정은 마지막에 변경하고 새 비밀번호로 다시 로그인해 주세요.
              
            
            
              
            
                
          
                
          
                
        
                
        
                
          
          
        
                
      
                
                    

    
      
                
        
                
          
                
            
                공고 탐색 방식
                
            
                세 가지 탐색은 목적과 비용이 다릅니다
                
          
                
          
        
                
        
                
          
                PAI 저장 공고는 바로 검토하고, 나라장터 공고와 사전규격은 필요한 건을 선택해 저장한 뒤 분석합니다.
                
          
                
            
                
              PAI 저장 목록
              
                PAI 저장 공고
                
              
                  
                
                • 저장된 전체 공고에서 즉시 검색
                  • 
                
                • 기존 자격·정량 점수와 판단 상태 확인
                  • 
                
                • 검색만으로 문서 분석 0회
                  • 
              
                
            
                
            
                
              나라장터 실시간
              
                용역 공고 조회
                
              
                  
                
                • 게시일 기준 최대 31일의 용역 공고명 조회
                  • 
                
                • 저장 전에는 자격 판단·정량 점수 없음
                  • 
                
                • 저장된 진행 공고에서 필요할 때 분석·판단 실행
                  • 
              
                
            
                
            
                
              입찰공고 전 단계
              
                사전규격
                
              
                  
                
                • 저장 자료와 나라장터 사전규격을 한곳에서 검색
                  • 
                
                • 필요한 건만 선택 저장하고 문서 분석은 별도 실행
                  • 
                
                • 입찰 GO/NO-GO가 아닌 요구조건 사전 검토
                  • 
              
                
            
                
          
                
          
                공고는 분석·판단 · 사전규격은 문서 분석검색·저장 단계에서는 문서 분석을 실행하지 않습니다. 분석 버튼을 눌렀을 때만 첨부문서 분석을 시작합니다.
