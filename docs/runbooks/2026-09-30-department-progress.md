# 진행 건의 부서별 조회

`입찰 검토 → 진행 건`의 제목은 `진행 건`, 목록 제목은
`참여·조건부 참여로 결정한 공고`다. 마감 임박 화면은 별도로 유지한다.

진행 건과 진행 건 중 마감 임박 화면에서 우측 선택창은 `진행 부서`다.
`전사`는 각 부서의 최신 판단이 GO 또는 CONDITIONAL_GO인 공고의 합집합,
개별 부서는 그 부서의 최신 판단으로 조회한다. 같은 공고는 한 번만
표시하고 담당자 판단 칸에 해당 부서와 판단을 함께 표시한다.
취소·마감 경과·결과 기록이 있는 공고는 기존 진행 건 기준에 따라 제외한다.

기존 인증된 부서 판단 일괄 조회를 사용한다. 이력은 부서별 revision,
기록 시각, ID 내림차순으로 최신 기록을 정한다. 이후 보류·불참 기록이
있으면 이전 참여 기록으로 목록에 남지 않는다. 조회가 끝나지 않았거나
실패하면 일부 기록을 전체 결과처럼 표시하지 않는다.

관리자도 전사 및 부서별 진행 목록을 조회할 수 있다. 상세의 판단 작성은
기존 로그인 부서와 권한을 유지하며, 조회 부서를 바꿔도 작성 주체는
바뀌지 않는다. 전체 공고 화면의 추천 부서는 기존 정렬 기능을 유지한다.
조건 링크에는 진행 부서를 포함한다. 진행 건 집계는 기존 dashboard API의
선택 부서별 최신 판단 집계와 동일한 기준을 사용한다.
