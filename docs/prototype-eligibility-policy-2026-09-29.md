# 참가 자격 프로토타입 정책 — 2026-09-29

정책 버전: `pai-loop-requirement-policy-2026.09.29-v14`  
회사 프로필: `2026.09.29-v4`

## 적용 기준

사용자가 승인한 프로토타입에서는 지정된 자격을 현재 회사 확인값으로 점검한다.
등록 업종·일반 입찰등록·국내법인·상호/대표자 일치·제재/유죄판결/결격 없음,
직접생산확인증명서와 기업 확인서 미보유, 비영리법인 여부가 적용 범위다.
과거 공고에도 현재 회사를 대입하며 과거 시점의 증빙 검증을 의미하지 않는다.

- **P 충족**: 요구 업종코드가 등록 목록에 있음(OR는 하나, AND는 전부 필요),
  국내입찰, 등록정보 일치, 제재·조세포탈 유죄판결 등 없음.
- **F 미충족**: 필수 업종코드 미등록, 직접생산확인증명서 또는 중소기업·소기업·소상공인
  확인서 미보유. 해당 조건에 적용되는 비영리법인 예외가 명시되면 그 예외로 P 가능.
- **R 확인 필요**: 회사 값 누락, 복수 조건의 AND/OR 불명확, 비영리 예외가 법령상 일부
  법인에만 적용되어 해당 여부가 불명확한 경우 등. 단순 재확인·증빙 갱신 알림은
  지정된 프로토타입 항목을 R로 바꾸지 않는다.

중소기업제품 구매촉진법의 단순 인용은 독립적인 중소기업 자격 요건으로 세지 않는다.
실적, 별도 인허가, 특정 지역 등 지정 범위 밖의 조건과 첨부 근거 검증은 기존 규칙을 유지한다.
`eligibility_assessment_mode`를 `DEADLINE_EVIDENCE`로 설정하면 엄격한 기준일 판정을 사용한다.

## 데이터와 평가 경로

- 배포 패키지의 공개 회사 프로필에는 18개 등록 업종(`9901` 포함), 직생·기업확인서
  미보유 및 제재·유죄판결 없음이 이미 구조화되어 있다.
- 상호/대표자 등록정보 일치 유지와 국내법인 사실은 이번 사용자 확인을 근거로 추가했다.
- 공개 정책 API는 공개 회사 프로필로 개별 자격을 점검한다.
- 저장 평가 엔진은 지정된 자격에 한해 저장된 최신 회사 값으로 임시 `prototype.*`
  입력을 만든다. 누락값은 R로 남고, 저장된 반대값을 프로필의 P로 덮어쓰지 않는다.
- 임시 입력은 회사 사실 테이블에 저장하지 않는다. 기존 회사 사실 기간과 정량평가
  입력을 바꾸지 않는다. 현재 회사 값의 해시를 분석 입력에 포함해 변경 시 재평가한다.
- 정책과 회사 프로필 버전을 올려 이전 판정을 재사용하지 않게 한다. 기존 저장 평가의
  총괄 판정은 재평가가 완료되어야 바뀐다. 기존 평가·추출 기록은 보존한다.

## 표시와 중복

개별 자격은 `P · 충족`, `F · 미충족`, `R · 확인 필요`로 표시한다.
전체 첨부 분석이 미완료라는 이유만으로 이미 검증된 출처에서 얻은 개별 P/F를 R로
바꾸지 않는다. 공고 전체 분석 상태와 저장된 종합 판정은 별도로 유지한다.

`items`는 모든 평가·출처 행을 그대로 유지한다. `display_items`만 동일 자격 키,
연산자, 요구값, 판정, 필수 여부, 제품코드가 같은 알려진 단일 조건끼리 묶는다.
다른 제품코드, 다른 판정, 미해결 복합 조건과 비영리 예외는 임의로 합치지 않는다.
각 표시 행의 `source_requirement_ids`, `source_conditions`에 원래 항목을 남기며
사용자가 펼쳐 볼 수 있다.

요청 예시의 9개 항목은 **P 4개 / F 2개 / R 0개**, 총 6개 조건으로 표시된다.
두 업종등록 문구, 두 중소기업 확인서 문구, 두 조세포탈 결격 문구가 각각 통합된다.

## 확인 범위

합성 공고로 예시 9개, 업종 AND/OR, 명시적 비영리 예외·의무 확대·불명확한 법령 범위,
누락 회사 값, 중복 보존, 실제 평가 저장 및 회사 값 변경 후 재평가를 검증한다.
기존 엄격한 정책은 별도 모드로 회귀 테스트한다.

운영 DB 조회는 자동 승인 검토에서 자격증명 사용 승인 부재로 거절되었다.
공개 서버 조회도 응답 제한시간을 초과하여 실제 운영 저장값 대조는 완료하지 못했다.
운영 배포·재분석은 이 변경의 로컬 검증과 별개이며 이 작업에서 실행하지 않았다.
