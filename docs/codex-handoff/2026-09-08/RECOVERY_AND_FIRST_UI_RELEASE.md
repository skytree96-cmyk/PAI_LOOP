# 자격·첨부 복구와 첫 화면 수정

PR111의 비영리 OR 경로 및 독립 중소기업 확인서 충족 경로 보완과 PR112의 XLS 처리 예산/인코딩 검증을 최신 main에 통합한다. 기존 담당자 결정과 분석 큐 설정은 유지한다. 배포만으로 저장된 전체 공고를 재분석하지 않는다.

## 화면 변경
- 상단 PAI 사용설명서 링크, 사이드바 Teams 버튼과 제공된 아이콘. 기존 Teams 연결 설정/URL 검증을 유지한다.
- 분석 실행 확인창에 현재 PAI 스타일을 적용하고, 비용·첨부 범위 설명과 취소 우선 포커스를 유지한다.
- 공고 단계 카드의 중복 여백을 제거하고 작은 화면에서도 보조 문구가 보이게 한다.
- 판정 근거의 잠정 배지만 생략한다. 검증됨/누락, 원문 위치 및 추출 신뢰도는 보존한다.
- 불러오는 중/완료/일부 오류/실패를 구분한다. dashboard.last_sync는 성공한 실제 PPS 수집 완료 시각만 제공하며 generated_at은 통계 조회 기준 시각으로 별도 유지한다.
- 정적 자산 버전 20260908-review-v1.

- 전체 통합 coverage와 GitHub 필수 CI는 진행 중. 결과는 PR에 갱신한다.
