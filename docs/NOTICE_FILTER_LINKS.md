# 저장 공고 검색 조건 링크

저장 공고 목록에서 **조건 링크 복사**를 누르면 검색 조건을 저장하거나 다른
사용자에게 공유할 수 있습니다. 링크를 연 사용자는 기존 로그인 절차를 거칩니다.

- 검색어, 자격 판정, AI 추천, 담당자 판단, 정렬, 부서 기준, 관심 키워드,
  목록 화면과 카드/표 표시를 복원합니다. 검색어는 200자, 관심 키워드는 500자까지입니다.
- 적용된 조건은 칩으로 표시하며 각각 지울 수 있습니다. 검색어·부서·관심 키워드를
  지우면 저장 공고를 다시 조회하고 나머지 조건은 현재 목록에 적용합니다.
- 조건 변경은 현재 주소에도 반영됩니다. 공유 URL에는 허용된 검색 조건만 넣으며,
  기존 상세 공고, 임의 쿼리, 세션 관련 값, URL 해시는 복사하지 않습니다.
- 클립보드가 차단된 브라우저에서는 직접 복사할 수 있는 링크 입력란이 표시됩니다.
- 링크는 조회 조건입니다. 데이터가 변경되면 결과도 바뀝니다. 담당자 판단은
  **링크를 연 계정의 부서** 기준이며 다른 부서의 권한을 전달하지 않습니다.
- 부서 목록과 판단 기록 로딩이 끝난 뒤 해당 조건을 적용합니다. 공유된 판단 조건이
  대기 중이면 목록을 숨기고 이유를 안내합니다. 관리자에게는 기존처럼 부서별 판단을
  상세에서 확인하도록 안내합니다. 부서 목록 로딩 실패 시 전사 기준 사용을 알립니다.
- 나라장터 실시간 조회·사전규격·낙찰 분석·결과 기록의 별도 검색 폼은 이번 범위에
  포함하지 않습니다. 이 링크를 여는 동작은 외부 조회나 AI 분석을 실행하지 않습니다.

URL 형식은 `filters=1`, `view`, `q`, `eligibility`, `recommendation`, `decision`,
`sort`, `department`, `keywords`, `layout`입니다. 선택 항목은 실제 목록에 존재하는
값만 복원하고 알 수 없는 값은 기본값으로 되돌립니다.

정량점수 계산과 승인 경계에는 변경이 없습니다.
