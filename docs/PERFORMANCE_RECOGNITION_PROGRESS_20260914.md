## 4. 참조 서식 증명

`src/pai_loop/quantitative_reference_context.py`는 같은 첨부의 정확한 원문 SHA·문자 위치·표/행 소유권에서 시작해 행→실적 서식→실적증명서의 명시적 참조만 따라간다. 전체 서식 조건을 보존하며 길이 제한 초과, 중복, 불완전한 중복 서식, 끊긴 참조, 다른 첨부, 부정문, 예시, 목차 대체는 차단한다. 참조 증명 자체는 저장·승격 권한이 아니다.

독립 모듈 검증에서 IBK native 원문의 2개 서식·680자를 연결했다. IBK PDF의 평탄화된 표제는 차단됐고, 다른 2사례는 행에 직접 번호 참조가 없어 연결하지 않았다. 따라서 이를 PDF 자동 연결 성공으로 세지 않는다.

## 5. 최종 통합 확인

**운영 자동 연결은 보류했다.** 실제 native 원문의 현행 QRE는 실적 행 영역을 문서 끝까지 열어 두고 있어 표 종료를 독립적으로 입증하지 못한다. 22줄 서식의 인용은 기존 4줄 근거 검색 한도에도 걸린다. 밖에 있는 조건을 허용하는 예외만 추가하면 잘못된 소유권을 승인할 수 있다. 따라서 `quantitative_rule_extraction.py`와 record fingerprint는 변경하지 않았다. 새로운 참조 모듈은 소유권이 증명된 입력을 위한 순수 진단 기능이며, 자동 파이프라인에 연결된 기능으로 보고하면 안 된다.
