# 부서별 공고 검색·우선순위 규칙 v0.3.0

## 목적

같은 공고라도 검색 주체의 사업영역과 담당 지역에 따라 검토 우선순위를 다르게 제시한다. 이 점수는 공고 발견과 배분을 위한 보조 지표이며, 입찰 참가자격의 `PASS / CHECK / CONDITION / ACTION` 판정을 변경하지 않는다.

## 공개 프로필 데이터

- 위치: `src/pai_loop/data/department_keyword_profiles.json`
- 기준 버전: `2026.08.17-1`
- 포함 항목: 그룹, 부서, 동의어, 강한 키워드, 보조 키워드, 제외 신호, 담당 지역, 점수 가중치
- 제외 항목: 임직원 이름, 연락처, 계정 및 기타 개인정보
- 전사 기본 키워드: `교육`, `컨설팅`

조직 개편 시 기존 파일을 덮어쓰지 않고 `version`을 올린 다음 변경 근거와 회귀 테스트를 함께 갱신한다.

## 점수 구성

| 신호 | 기본 가중치 | 의미 |
|---|---:|---|
| 사용자가 입력한 검색어 | +24 | 현재 검색 목적에 직접 일치 |
| 전사 강한 키워드 | +10 | 교육·컨설팅 기본 사업 |
| 전사 보조 키워드 | +5 | 연수·과정개발·워크숍 등 |
| 선택 부서 강한 키워드 | +18 | 해당 부서 핵심 사업 |
| 선택 부서 보조 키워드 | +9 | 해당 부서 인접 사업 |
| 담당 지역 | +14 | 지역본부 관할 지역 |
| 비주력 제외 신호 | -30 | 시설공사·식자재 등 비주력 공고 |

표시 점수는 `0~100`으로 제한하지만 감사용 `raw_score`와 키워드별 `score_breakdown`도 반환한다. `department_score`는 부서·지역 신호만 합산하므로 모든 부서에 공통으로 붙는 교육·컨설팅 점수와 구분된다.

## 우선순위 구간

- `HIGH / 최우선`: 55점 이상
- `MEDIUM / 우선`: 30점 이상
- `WATCH / 검토`: 10점 이상
- `LOW / 낮음`: 10점 미만

상위 추천 부서는 실제 부서 또는 지역 키워드가 일치해 `department_score > 0`인 경우만 표시한다. 단순히 전사 공통 키워드만 일치한 공고에 임의의 담당 부서를 배정하지 않는다.

## API 사용 예시

```text
GET /api/v1/departments/keyword-profiles
GET /api/v1/notices?department_id=future-competency-solution&search_keywords=승진후보자,역량평가
```

`search_keywords`는 쉼표, 줄바꿈 또는 `|`로 최대 20개까지 입력한다. 여러 검색어는 OR 조건으로 공고를 찾고, 일치한 검색어는 점수 근거에 남긴다.

## 운영 원칙

1. 우선순위는 제목·기관·공고 분류에 대한 설명 가능한 문자열 매칭이다.
2. 자격 판정, 정량평가, 최종 입찰 결정과 분리한다.
3. 사람이 최종 담당 부서와 입찰 여부를 확인한다.
4. 웹 배포 시 동일한 버전의 JSON을 애플리케이션 패키지에 포함한다.
5. 사용자별 검색어 자체에는 개인정보나 비공개 고객정보를 입력하지 않는다.
