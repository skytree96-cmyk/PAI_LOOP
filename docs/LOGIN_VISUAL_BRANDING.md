# 로그인과 업무 화면의 PAI 표시

로그인 화면은 공개 소개 페이지와 같은 Paperlogy CDN, PAI 워드마크와 점,
P 파비콘을 사용한다. 기본 색은 `#12568e`, 본문은 `#122d42`이며 서체 굵기와
약한 양의 자간, 둥근 버튼도 소개 페이지에 맞춘다. 업무 사이드바의 워드마크는
같은 형태를 유지하고 남색 배경에서 읽을 수 있도록 흰색으로 표시한다.

Paperlogy는 소개 페이지와 동일한 외부 스타일시트를 로그인 HTML에서 직접
로드한다. 로컬 폰트 파일을 추가하거나 `app_access`의 익명 접근 허용 범위를
넓히지 않는다. CDN을 사용할 수 없는 환경에서는 시스템 서체로 대체되며,
서체 로드 결과가 인증이나 보호된 데이터의 접근 조건을 바꾸지 않는다.

좌하단 계정 표시는 확인된 세션의 등록 `department_name`을 사용한다.
관리자는 `개발자 관리자`로 표시하며, 부서명이 없으면 이전 이름이나 계정
아이디로 추측하지 않는다. 세션 변경·조회 실패·로그아웃 시 표시는 비워진다.
서버도 계정의 `department_id`에 매핑된 부서명으로 판단·결과의 작성자를
저장하므로 이 화면 표시는 기록 소유권을 변경하지 않는다.

로그인 스크립트, 입력 ID·label·autocomplete, 초기 비활성 상태, 오류 및
명시적 재로그인 동작은 유지한다. 앱·로그인 CSS·파비콘의 캐시 키는
`20260908-login-brand-v1`이며 로그인 JavaScript는 내용 변경 없이 기존 키를 유지한다.
