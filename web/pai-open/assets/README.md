# PAI public media

The public page at https://pai.kma.or.kr/open offers two video tabs:

- `pai-ad-v11.mp4`: approved V11 rhythm edit, 99.4 seconds, 1920 x 1080,
  30 fps, with the original AAC soundtrack. Copied without transcoding from
  the final supplied advertisement; SHA-256
  `506d403446ebd0d6bfe4fcdd6809180724771230b92302fee2579093f1287304`.
- `pai-ad-poster.webp`: frame from the advertisement for its initial preview.
- `pai-product-tour.webm` and `pai-product-poster.webp`: existing 60-second
  QHD studio tour of actual PAI interfaces using example data.
- `pai-screen-1.webp` through `pai-screen-8.webp`: existing scroll-story images.

Only these twelve files are media assets in the static build. Server and wheel
allowlists include them explicitly. Source footage, capture inputs and this
README are not public assets. Native controls allow sound and playback changes;
reduced motion disables autoplay. The advertisement is the first/default tab.
