# PAI motion assets

Original abstract graphics generated locally using Canvas and MediaRecorder. No footage, company materials or real application data are used.

- `pai-loop-background.webm`: silent VP9, 1280 x 720, 8 seconds, 692,578 bytes. Recording requested 24 fps; the browser stored 191 frames.
- `pai-loop-poster.webp`: 1280 x 720 static fallback, 11,976 bytes.

The mathematical loop boundary matches exactly. The final WebM seek index was checked after recording. The public page respects reduced-motion preferences and includes a pause control.
